
MODASTORE PRO - SISTEMA DE LOJA DE ROUPAS

REQUISITOS:
- Python instalado
- VS Code ou PyCharm
- Conexão com a internet para instalar as bibliotecas

INSTALAÇÃO:
1. Abra a pasta ModaStore no editor.
2. Abra o terminal dentro da pasta principal.
3. Execute:

python -m pip install -r requirements.txt

EXECUÇÃO:
Execute o comando:

python -m streamlit run app.py

FUNCIONALIDADES:
- Página inicial
- Cadastro de roupas
- Consulta e controle de estoque
- Registro de vendas
- Dashboard com gráficos
- Relatórios de produtos e vendas

ARMAZENAMENTO:
Os dados são salvos localmente em arquivos JSON
na pasta dados, criada automaticamente pelo sistema.
